# vizguide
## 研究问题
本研究从通过对不同机构设计规范进行建模和操作，以支持知识驱动的可视化生成。

**研究对象（What）：Institutional Visualization Knowledge**
  - 定义：机构在长期数据传播实践中沉淀下来的、编纂于其风格指南或设计系统中的可视化设计知识，涵盖图表选择、视觉编码、叙事组织、视觉强调、注释策略与版式规范等，塑造了该机构独特且可辨识的数据表达方式。

**研究视角（Why this lens）**
  - 定义：将设计领域的知识获取并构造为可表示、可执行的知识模型，使其能被系统理解和执行。

**研究方法（How）**
  - 表示：机构设计人格表示方法（Institutional Design Persona）：针对需要统一表示异构、层次混杂的机构可视化设计知识，同时突出不同机构可视化设计知识的独特性的挑战，我们借鉴人格心理学 McAdams 三层次模型（1995/2006），将每份指南统一编码为三层并装配为智能体人格：
    - L1 气质签名 = 恒定规则与令牌（must/never，无条件；Economist 命名色板、BBC 全文字左对齐）；
    - L2 特征适应 = 条件规范（when→then；单序列→BBC 蓝、健康题材→Teal）；
    - L3 叙事认同 = 设计哲学与理由故事（Less is more；Clarity First）。
L1: Fixed rules
  - Color: 无条件适用的色板、品牌色等规定。
  - Typography：无条件适用的字体样式、字号、字重、文本层级等规则。
  - Layout：无条件适用的对齐、留白、间距、与位置布局等规则。
  - Anatomy：图表的固定构成、标题、副标题、注释、标签、图例、坐标轴、网格、标记、来源等。
  
L2：Condition rules
- Based on Data：由数据形态、语义或规模触发。比如当只有一个数据系列时，使用xx。
- Based on Intent：由要表达的问题或传播目标触发：比较、趋势、关系、构成、强调、讲述变化等。
- Based on Audience：由受众的身份触发，比如受众背景，知识、语言、背景、阅读能力或无障碍需求。

L3: Design Philosophy
- Clarity：注重可视化设计的清晰、简洁、降低认知负担。
- Accuracy：注重可视化设计展示的数据准确性。
- Integrity：注重可视化设计的完整性，比如包括几乎全部的图表组成anatomy，比如source、grid等。
- Narrativity：以叙事、重点、情境或情感关联帮助读者理解数据。
- Accessibility：注重数据可视化的可及性，无障碍配色等，面向不同能力、经验与背景的读者平等理解和使用。
- Effectiveness：注重可视化设计的功能性，比如能清晰展示数据趋势等。

  - 推理：快慢双通道规范执行（Fast–Slow Norm Execution）：针对设计知识推理过程的强情境依赖，现有方法（纯RAG检索，整个指南模版套用）模板整体套用，无法根据不同情景调用不同设计知识的挑战。

 **应用场景定位**
 设计探索工具Institution-aware Design Exploration System：帮助非专业或专业设计师探索不同机构设计专家会如何设计可视化，为设计师提供Design Inspiration。用户会召唤有不同机构设计指南知识表示的专家，他们会进行角色扮演，基于他们的设计知识检测当前图表的问题，然后通过推理使用自己的知识提出修改建议。
  用系统流程：
  在前端setting panel,用户上传原始图表vega-lite，并可用自然语言说明意图；召唤机构，可以直接选择多个现有已解析好的机构persona agents，也可以上传新的规范让agent解析建模形成具有对应机构的persona agent。
  系统里被选择的每个persona agents开始理解原始图表，以机构自身的persona和快慢通道推理生成对应修改版本展示在前端proposal panel。
  在前端design panel,列好图表设计问题议题，每个议题可能是由多个机构都提到的。由最多到少排列议题。每个议题下面又分层，分成每个机构设计agent的解决方案，用户可以选择加号代表采纳。
